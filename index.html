Kolik mohu maximálně nabídnout?

Vyber nabídku tlačítkem „Spočítat kupní limit“ nebo vyplň vlastní model.

Při prvním použití vyplň i nuly, aby bylo jasné, že jsou náklady posouzené. Rezerva 15 % a ROI 20 % jsou upravitelné modelové hodnoty. Úrok počítáme jednoduše z konstantní čerpané části kupní ceny; splácení a postupné čerpání model neřeší. Úroky na rekonstrukci zahrň do dalšího financování. Zisk je před daní z příjmů; DPH a daňový režim konkrétního obchodu řeš samostatně.

Jak se počítá limit a odolnost obchodu

Celkové náklady = kupní cena + rekonstrukce s rezervou + ostatní náklady + úroky + provoz + prodej. Pro ROI se maximální kupní cena řeší včetně úroků závislých na kupní ceně. Zátěžový scénář sníží prodejní cenu o 5 %, zvýší samotný rozpočet rekonstrukce o 15 % a prodlouží držení o 3 měsíce. Rezerva zůstává navíc. Nejde o předpověď trhu.

Přidat investiční příležitost

Rezerva se počítá z rozpočtu rekonstrukce. Výsledky nezahrnují automaticky daně, financování, čas držení ani náklady prodeje; případné odhady vlož do „Další náklady“.

Tržní srovnání podle lokality a dispozice

Zadej ověřenou referenční cenu za m² z porovnatelných nabídek. Bez referenčních dat aplikace žádnou tržní cenu nevymýšlí. Rozdíl od benchmarku je pouze orientační, neznamená automaticky zisk.

Web automaticky načte poslední publikovaný přehled při otevření. Sběr nabídek provádí samostatná plánovaná kontrola; její úspěch posuzuj podle data výše. U každé nabídky ukládáme historii zadaných kupních cen při opakovaném importu stejného URL; historii lze uchovat v JSON záloze.

Jak výsledky počítáme

Celkové náklady = kupní cena + rekonstrukce + rezerva z rekonstrukce + další náklady. Hrubý zisk = odhad prodejní ceny − celkové náklady. ROI = hrubý zisk / celkové náklady × 100. Cena za m² = kupní cena / užitná plocha. Ukázková data jsou smyšlená a neslouží jako odhad místního trhu.
